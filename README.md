# Worldforge screenshots

This branch holds the UI screenshots that tickets attach as evidence (`docs/screenshots/<phase>/…`).
They used to live on `main`; they were moved here (Phase 5, ticket 5.8) so that cloning, CI checkouts
and deploys stay small. The branch has no shared history with `main` and is append-only.

To add screenshots, see `docs/DEVELOPMENT.md` "Screenshots" on `main` (`tools/screenshots/publish.sh`).
