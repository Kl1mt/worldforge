# Screenshots

Screenshots no longer live on `main`. They are on the **`screenshots` branch**, at the same paths
(`docs/screenshots/<phase>/…`), e.g.
`https://github.com/Kl1mt/worldforge/blob/screenshots/docs/screenshots/phase-5/boards-level-desktop.png`.

The scripts in `tools/screenshots/` still write here locally (this folder is git-ignored); publish them
with `tools/screenshots/publish.sh <folder>`. See `docs/DEVELOPMENT.md` "Screenshots".
